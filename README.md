# Retirement Savings Calculator  
28년 동안 은퇴자금을 모으기 위한 시작 월 저축액을 계산하는 파이썬 프로그램입니다.  
인플레이션을 반영하여 저축액이 해마다 증가하는 방식으로 미래 가치를 추정합니다.

## 주요 기능
- 인플레이션과 수익률을 반영한 복리 미래가치(FV) 계산
- 목표 미래가치에 도달하기 위한 최적의 시작 월 저축액 탐색
- 결과 출력: 시작 월 저축액 및 예상 도달 금액 (2053년 기준)

## 사용 방법
1. `retirement_savings_calculator.py` 실행
2. 콘솔에 아래와 같은 출력 확인:

```
[추천 시작 월 저축액]: 891,000원  
[2053년 도달 예상 금액]: 2,194,XXXX,XXX원
```

## 기본 설정값
- 목표 은퇴 자금: 3.3억 (순현가치) → 약 21.94억 (28년 후 표기가액)
- 연 수익률: 7%
- 연 인플레이션율: 7%
- 기간: 28년

## 요구 사항
- Python 3.x
